## 📋 نظرة عامة

<div dir="rtl" align="right">

**دشليون** برنامج محاسبي متكامل بواجهة عربية كاملة من اليمين إلى اليسار، يدعم **الفاتورة الإلكترونية السعودية (ZATCA)** ويوفر حلاً شاملاً لإدارة المشاريع التجارية والصناعية بكل احترافية.

تم تصميم البرنامج خصيصاً للمتطلبات المحاسبية العربية والسعودية، مع واجهة سهلة الاستخدام تناسب جميع مستويات الخبرة.

### ✨ لماذا دشليون؟

| | |
|---|---|
| 🇸🇦 **دعم الفاتورة الإلكترونية ZATCA** | جاهز لمتطلبات الفوترة الإلكترونية السعودية والمواصفات الرسمية |
| 🌐 **واجهة عربية كاملة** | تصميم من اليمين إلى اليسار (RTL) سهل الاستخدام وحدسي |
| 🖥️ **يعمل على Windows و macOS** | مرونة كاملة في اختيار نظام التشغيل |
| 🔗 **ربط أكثر من جهاز** | تابع عمل منشأتك من أي جهاز عبر الخادم الرئيسي |

</div>

## 🧩 الأقسام والمميزات

<div dir="rtl">

| القسم | المميزات |
|---|---|
| **🛒 الفواتير** | فواتير مبيعات ومشتريات ومرتجعات، حركة مخزنية (إدخال، إخراج، مناقلة)، بضاعة أول المدة، عروض أسعار وطلبات |
| **📄 القيود المحاسبية** | قيود قبض ودفع ومركّبة وافتتاحية، مع أنواع قيود مرنة حسب حاجة منشأتك، ودفعات الإيجار والضرائب |
| **🏦 الحسابات** | شجرة حسابات واضحة، كشف حساب لأي عميل أو مورد، دفتر أستاذ، ميزان مراجعة، ومعالجة الأرصدة |
| **📦 المنتجات والمخزون** | تنظيم المنتجات بمجموعات ووحدات وشجرة سهلة، تعديل الأسعار فردي أو جماعي، تسوية المخزون |
| **⚖️ نقطة التعادل** | معرفة نقطة تغطية نفقاتك الشهرية بعرض سنوي واضح |
| **📊 الرسوم البيانية** | رسوم توضح حركة المنتجات والفواتير والقيود لفهم أداء منشأتك بنظرة واحدة |
| **🔒 الإغلاقات** | إغلاق يومي للمبيعات وصندوق النقدية لضبط الدورة المالية |
| **👥 التعريفات** | فروع ومستودعات وعملات وطرق دفع وسائقون، ومندوبو مبيعات بنظام عمولات كامل |
| **🛠️ الأدوات والإعدادات** | إدارة المستخدمين والأدوار والصلاحيات، سجل نشاط كامل، نسخ احتياطي، وتدوير السنة المالية |
