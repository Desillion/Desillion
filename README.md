## 1️⃣ نظرة عامة على البرنامج

> دشليون (Desillion) نظام سطح مكتب (Electron) يعمل دون اتصال دائم، بقاعدة بيانات MySQL محلية لكل سنة مالية مستقلة، وواجهة عربية كاملة (RTL) مع دعم التاريخ الهجري والميلادي، والوضع الداكن، والنوافذ المتعددة.

| الميزة | الوصف |
| --- | --- |
| عربي كامل | واجهة عربية RTL مع تقويم ميلادي وهجري وتنسيق أرقام وعملات حسب إعدادات الشركة. |
| سنة مالية مستقلة | كل سنة مالية قاعدة بيانات مستقلة + تدوير سنوي للأرصدة والحركات. |
| يعمل دون إنترنت | تطبيق سطح مكتب Electron + MySQL محلي — بياناتك داخل شركتك. |
| نوافذ متعددة | فتح الفواتير والقيود في نوافذ مستقلة قابلة للتكبير والعمل المتوازي. |
| صلاحيات دقيقة | صلاحيات على مستوى القوائم وأنواع الفواتير والقيود لكل مستخدم ودور. |
| سجل نشاط | تتبع كل عملية (إنشاء/تعديل/حذف) مع عرض تفاصيل الفاتورة والقيد قبل وبعد. |

## 2️⃣ الفواتير بأنواعها

> منظومة فواتير مرنة بأنواع قابلة للتخصيص (اسم، لون، قسم، صلاحيات، تصميم طباعة)، تغطي دورة البيع والشراء والمخزون كاملة.

| الميزة | الوصف |
| --- | --- |
| فواتير المبيعات والمشتريات | إنشاء وبحث وفلترة وطباعة مع دعم الضريبة والخصومات والدفعات المتعددة والعميل/المورد. |
| مرتجعات البيع والشراء | مرتجعات مرتبطة بالفواتير الأصلية مع عكس أثر المخزون والحسابات تلقائياً. |
| الحركات المخزنية | إدخال / إخراج / مناقلة بين المستودعات + بضاعة أول المدة. |
| عروض الأسعار وطلبيات الشراء | عرض سعر قابل للتحويل لفاتورة، وطلبية شراء لدورة الاعتماد. |
| أنواع فواتير مخصصة | إضافة أنواع جديدة بألوان وأقسام وصلاحيات عرض/إنشاء لكل نوع على حدة. |
| بحث وفلترة متقدمة | فلترة بالتاريخ والنوع والفرع والمندوب والسائق وحالة الدفع، مع أعمدة قابلة للتخصيص. |
| ربط محاسبي تلقائي | كل نوع فاتورة يولّد قيده المحاسبي تلقائياً حسب إعدادات الحسابات. |
| طباعة وباركود وQR | تصاميم طباعة مخصصة لكل نوع + باركود المنتجات ورمز QR للفاتورة الإلكترونية. |

| دفعات الإيجار | جدولة ومتابعة دفعات عقود الإيجار (مستحق/مدفوع/متأخر) مع التنبيه. |
| دفعات الضرائب | جدولة ومتابعة الدفعات الضريبية المستحقة والمدفوعة. |
| ربط بالفروع | كل قيد مرتبط بفرع ومستخدم مع سجل نشاط كامل. |

| معالجة الأرصدة | إعادة احتساب أرصدة الحسابات بعد التعديلات لضمان تطابق التقارير. |

| الميزة | الوصف |
| --- | --- |
| بطاقة المنتج | اسم، باركود، مجموعة، وحدات، أسعار بيع/شراء، حد الطلب، صور وملاحظات. |
| شجرة المنتجات | عرض شجري حسب المجموعات للوصول السريع والتنقل. |

| معالجة حركات المخزون | إعادة بناء أرصدة المخزون من الحركات لضمان الدقة بعد التعديلات. |
| تسوية المخزون (الجرد) | تسوية الفروقات بين الفعلي والدفتري بقيود مخزنية موثقة. |
| تقرير حركة المنتجات | وارد/صادر/رصيد لكل صنف بفترة وفرع ومستودع مع التصدير. |
| استيراد المنتجات | استيراد من Excel بكميات كبيرة مع التحقق من الأخطاء قبل الاعتماد. |
